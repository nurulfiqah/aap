## 5. Backfill sekali — Fixit Category sync untuk Case Type sedia ada

Auto-sync (`aapSyncFixitCategoryForCaseType()`) cuma trigger bila admin save/edit/toggle satu Case Type lepas ni — Case Type yang **dah ada sebelum** feature ni (Customer Refund, Cash/Stock Discrepancy Write-off, Course Fee Refund/Waiver) takkan auto-dapat row `fixit_category` tanpa backfill ni.

Buat fail baru `aap/backfill_fixit_category_sync.php` (untracked by git, copy terus) dengan content ni:

```php
<?php
// One-time backfill - run once, then delete.
ob_start();
require_once('../lock_adv.php');
$connect = 1;
include('../common/index_adv.php');
ob_end_clean();

if (!isset($conn) || !($conn instanceof mysqli)) {
    die("Database connection not available.");
}
require_once('aap_lib.php');

$res = $conn->query("SELECT id FROM aap_case_types");
while ($row = $res->fetch_assoc()) {
    aapSyncFixitCategoryForCaseType($conn, (int)$row['id'], (int)$id_user);
    echo "Synced case type {$row['id']}<br>";
}
echo "Done. Delete this file now.";
```

Buka dalam browser (login dulu): `https://<production>/odb/aap/backfill_fixit_category_sync.php`

Lepas keluar "Done." — **padam fail ni terus**.

## 6. Check siapa hilang admin access (perubahan besar — baca ni)

Admin AAP sekarang **hanya** `staff.aap = 1`, full stop. Grade ≥ 4, Digital Innovation (dept 16), dan union OKR/ATEM (`staff.okr`/`staff.atem`) **tak lagi** bagi admin access kat AAP.

```sql
-- Senarai staff yang DULU admin (grade4/DI/okr/atem) tapi sekarang HILANG access
-- (sebab aap bukan 1)
SELECT id, nama_staff, grade, department, aap, okr, atem
FROM staff
WHERE recycle != 1
  AND (grade >= 4 OR FIND_IN_SET(16, department) OR okr = 1 OR atem = 1)
  AND (aap IS NULL OR aap != 1);
```

Mana-mana staff dalam list ni yang **perlu kekal** admin AAP, kena set `staff.aap = 1` secara manual (via `admin/aap_settings.php`'s AAP Access panel).
